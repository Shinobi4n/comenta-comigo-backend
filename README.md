## Comenta Comigo

API REST em Spring Boot da plataforma Comenta Comigo, uma plataforma para opinar sobre filmes, séries, álbuns, livros e tudo que interessa você e seus amigos!

## Integrantes
- Ruan Araujo dos Santos

## Tecnologias

- **Java 21** – Linguagem de programação.
- **Spring Boot 4.1.2** – Framework backend.
- **Spring Web MVC** – Desenvolvimento da API REST.
- **Spring Data JPA** – Persistência de dados.
- **Jakarta Bean Validation** – Validação de dados.
- **PostgreSQL** – Banco de dados relacional.
- **Apache Maven** – Gerenciamento de dependências e build.
- **JUnit / Spring Boot Test** – Estrutura de testes automatizados.
